# 設計上の決定

## イベントタップは `.defaultTap`
`.listenOnly` は入力監視権限が必要で、Xcode 実行時に動かなかった。`.defaultTap` ならアクセシビリティ権限だけで動く。イベントは変更せず常に通す。

## App Sandbox は無効
`CGEventTap` を使うため。App Store 配布は想定しない。

## 権限状態は `PermissionState` で反映
メニューの「アクセシビリティ権限を許可…」が許可後も消えなかった問題の対策。1秒ごとに再確認する。

## 削除した機能（復活させない）
- **アプリ連動の自動切り替え**: 実装後、ユーザー指示で機能ごと削除（UI、`AppContextSwitcher.swift`、設定キー、テスト）。
- **切り替え時の HUD（画面中央の「A」「あ」）**: 不要との指示で削除（v0.1.1）。

## 未実装の候補
触覚/サウンド、Developer ID 署名と公証、自動アップデート（Sparkle または GitHub Releases の通知）、ログイン時自動起動（SMAppService）。
